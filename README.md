# Velvet Crimson 🍷✨

Velvet Crimson is a luxury fashion haute couture e-commerce platform. It provides a premium, responsive, and beautifully animated shopping experience for high-end fashion, including bespoke sarees, evening gowns, and artisanal tops.

## 🌟 Features
- **Premium UI/UX:** High-end aesthetic with a custom color palette, smooth animations, and a modern layout.
- **Bilingual Support:** Full English and Bengali (বাংলা) language support.
- **Product Catalog:** Interactive product cards, category filtering, and quick view modals.
- **Cart & Wishlist:** Fully functional slide-out cart and wishlist management.
- **Admin Portal:** Manage products, categories, orders, and privileges with a dedicated dashboard.
- **Real-time API Integration:** Node.js Express server seamlessly integrated with Vite and MongoDB.

## 🛠️ Tech Stack
- **Frontend:** React 19, Vite, Tailwind CSS 4, Framer Motion, Lucide React
- **Backend:** Node.js, Express
- **Database:** MongoDB
- **Language:** TypeScript

## 🚀 Getting Started

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation
1. Clone the repository and navigate to the project folder:
   ```bash
   cd velvet-crimson
   ```
2. Install the dependencies:
   ```bash
   npm install
   ```

### Running Locally
To start both the Vite development server and the Express backend simultaneously:
```bash
npm run dev
```
Your application will be available at [http://localhost:3000](http://localhost:3000).
